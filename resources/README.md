# Bakong & KHQR Digital Assets & Brand Resources

This directory contains standardized, clean vector and raster brand assets, acquiring bank emblems, and physical merchant display materials conforming to the National Bank of Cambodia (NBC) KHQR Branding Guidelines.

## Directory Structure

```
resources/
├── bank-logos/           # Standardized vector logos of 32 Cambodian financial institutions
├── khqr-brand/           # Official KHQR identity marks, badges, and export stands
├── merchant-materials/   # Merchant POS stands, display frames, and KHR/USD currency badges
├── fonts/                # Inter, Nunito Sans, and Sora typography families
├── banking-cards/        # Responsive vector backgrounds (banknote, dragon, liberty) and currency badges
├── coaches/              # 28 Coach avatars and icons (14 personalities)
├── avatars/              # 154 Player and personality avatars
├── sounds/               # 168 Audio effects (coins, ui, game, progression)
└── catalog.json          # Complete JSON metadata of all 376 assets
```

### 2. KHQR Brand Assets (`resources/khqr-brand/`)
Official KHQR identity assets in crisp vector (`.svg`) and transparent high-resolution (`.png`) formats:

* `khqr-logo.svg`, `khqr-logo.png`: Standard primary KHQR emblem
* `khqr-logo-red.svg`, `khqr-logo-red.png`: Bakong Bravery Red (`#E1232E`) mark
* `khqr-available-here.svg`, `khqr-available-here.png`: Official acceptance badge
* `khqr-digital-payment.svg`: Digital payment mark
* `khqr-merchant-stand.svg`: Production-ready vector merchant QR acrylic stand
* `khqr-tag.svg`: Vector tag component
